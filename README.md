# Пинг-понг

Классическая игра «Пинг-понг» для двух игроков на одном компьютере, написанная на Python с использованием библиотеки pygame.

## Описание

Игроки управляют ракетками по краям экрана и отбивают мяч. Проигрывает тот, кто пропустил мяч - он улетает за край экрана. После проигрыша можно начать заново, нажав пробел.

## Инструменты

- Python 3
- pygame ( pygame-ce )

## Установка

```bash
pip install pygame
```

## или
```bash
pip install pygame-ce
```

## Подготовка
```bash
python -m venv venv
```

# Windows
```bash
venv\Scripts\activate
```

## или

## macOS / Linux

```bash
source venv/bin/activate   # macOS / Linux
```

